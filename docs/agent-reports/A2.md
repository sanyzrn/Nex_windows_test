## Changes

- `DesktopAction` gives custom pointer controls a single keyboard target, Enter/Space
  activation, localized semantics and keyboard-only focus outlines. Its Material
  variant retains the existing InkWell pointer ripple. Disabled actions are skipped.
- `DesktopFocusRing` adds no Tab stop or size change. Keyboard-focused controls own
  a nonmodal panel hold, released on focus loss, pointer mode or disposal; this lets
  a keyboard user leave an editor without the edge panel hiding mid-interaction.
- Custom utility buttons/tabs, clipboard/snippet rows, folder/text-tool tiles,
  media/volume controls, color controls/swatches, emoji controls and dock tiles now
  use the common keyboard action. Password copy controls announce the action rather
  than exposing the password as their label.
- Added missing labels to clear-search controls, tool pagination, AI dialog close,
  API-key visibility, snippet delete and AI tool buttons. `ItemAction.tooltip` is
  required. An existing outer AI tooltip moved onto the actual IconButton.
- Labelled the capture checklist toggle and settings controls; added focus outlines
  to capture actions, reader actions, settings/provider links, appearance choices,
  checkboxes and icon buttons. Existing native theme borders remain in use.
- Window Tab order follows widget/source order in both directions. Removed extra
  stops from focus observers and from the More menu's presentation tile. Kept the
  More menu's single real action and visible focus indicator.
- The existing hygiene gate now rejects unlabelled Material IconButton constructors
  (including filled/outlined variants); no workflow logic was changed in this part.
- The window navigation test now selects its header Back button by a stable key:
  the embedded tool's already-existing Back button now has the same localized label.
  No assertion or test was deleted, and both controls retain their behavior.
