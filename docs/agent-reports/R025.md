# 0.25.0 — panel and reminder feedback

Owner requested implementation and publication on 2026-10-22, with lean checks.
Base: released 0.24.0, main 318e809. Version prepared as 0.25.0+19.

- Reminder delivery receipts now drive the library's Today strip and card badge.
  A delivered one-off stops appearing overdue. Due metadata is preserved for
  Snooze/Done and changed due times have distinct receipts. Failed delivery is
  not treated as success; repeating reminders continue to show their next turn.
- Gallery/list switches are hidden only in the panel library.
- Dock scale is 75–125%, independent of the 360px flyout and its contents.
  Global hit rectangles, hover/active anchors and reorder geometry follow scale.
- Reveal area has width 1–12px, height 24–400px and vertical position in 0.1%
  increments across the selected monitor's work area. Default is 2×120px centered.
  Settings → Display offers a preview and reset. Outside this area there is no
  proximity peek; the keyboard shortcut remains available.
- Settings icons (panel, slim and wide window rails) and the About settings row
  listen to the existing validated update service. The red dot appears only for
  an available newer release; widgets do not initiate network checks.
