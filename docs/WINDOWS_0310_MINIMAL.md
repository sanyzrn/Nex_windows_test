# Windows 0.31.0 — a quieter window

The window worked, and it was busy. Every page spoke at once: a hero line and
three counters above the editor, six action tiles under it, a "Pinned" card
beside it, a promo card for the assistant, then the notes; a Tools page of
large gradient tiles that each said "Open this tool"; a Settings page with a
banner, a capsule search and option tiles a hundred pixels tall. The type was
tuned for a phone held at arm's length, on a screen read at a desk.

The reference for this round is a minimal notes app: a slim sidebar, a search
bar, a grid of small pastel cards — title, a few lines, a tag and a time —
and white space doing the work that borders and headings did.

## The look

- **Small, calm type.** The window sets its type 8 % under the panel's
  (`kWindowTypeDensity`); the Text size setting and the system's scale still
  apply on top, and nothing is shrunk by a transform.
- **A slim rail**, 192 px: a small wordmark, one quiet "New note" button, four
  rows of 34 px with a neutral wash for the current place, Settings at the
  foot, and one row of small icons (theme, shortcuts, search, edge panel). The
  privacy line is the shield's tooltip.
- **One idea per page.** Capture is an editor and notes. Tools is a grid. The
  assistant card shows only once a provider is set and a brief exists.
- **Cards, not boxes.** A note is a small tinted card (`_NotePreview`, the
  Library's board card): title, a few lines, tag dot, time. Tool and shelf
  entries are one shape: a 34 px chip, a name, one line.
- **Rounded 12–16, hairline borders, no shadows** except where the shared
  surfaces already carry the faintest one.
- Colour is the tag's or the tool's hue and the accent on what is live; nothing
  else is coloured.

## Phases

1. **Frame — done in 0.31.0.** Type density, the slim rail, the page header,
   shared surfaces (`NexSoftCard` 16 px, `NexIconBadge` 36, `NexSettingsLink`,
   `NexFeatureCard`), a `dense` mode for `NexWorkspaceDestination`.
2. **Home and Library — done in 0.31.0.** Capture without hero/counters/shelf,
   a calm editor with a row of small action chips, pinned and recent notes as a
   card grid with counts beside the headings; Library board cards at 200 px,
   14 px padding, four columns at 1200 px, a rounded-rect search.
3. **Tools and Settings — done in 0.31.0.** One compact tile for tools and for
   the Private / Everyday shelves; Settings without the banner, with smaller
   rows, cards and option tiles.
4. **Next.** Library: tag and type filters moved into the rail (with counts, as
   in the reference) so the chip row under the search can go; the list view and
   the reader at the same density; the note reader's toolbar. Intelligence page
   and its settings at the same type scale. Dialogs and pickers (palette,
   reminder, tag manager) at 12 px radius. A pass over the edge panel, which is
   deliberately unchanged here.
5. **Windows tools.** The Tools page is now a plain grid with a "Windows"
   section waiting: drop a tile in `NexToolsShelves` (`collection_shelves.dart`)
   or add an id to the tool registry (`core/registry.dart`) and it takes the
   same shape. Nothing else needs to change for a new tool to look at home.

## Checks

- English and Persian, light and dark, 1440 × 900 and the 960 / 700 / 460
  widths; text scales 1.0, 1.5 and 2.0 (the existing text-scale tests).
- Compact (< 620 px) pages keep their layout: editor first, actions as tiles.
- Windows baselines are regenerated by the repository workflow, not by hand;
  tolerances are untouched.
