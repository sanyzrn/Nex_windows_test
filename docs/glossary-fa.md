# واژه‌نامهٔ فارسی نکس ویندوز

این واژه‌نامه مرجع متن‌های رابط، ترجمه‌های جدید و بازبینی‌های بعدی است.
لحن کوتاه، روشن و صمیمی است: «انتخاب کن»، «دوباره تلاش کن»؛ بدون اصطلاحات مبهم
یا وعده‌ای دربارهٔ قابلیتی که هنوز پیاده نشده است. پیام‌های تأیید و خطا دقیق‌اند.

نیم‌فاصله در «می‌شود»، «یادداشت‌ها»، «به‌روزرسانی»، «گفت‌وگو» و «میان‌بر»
رعایت می‌شود. از «ی» و «ک» فارسی، نشانهٔ «،» و سه‌نقطهٔ «…» استفاده می‌شود.
نام برندها، نام مدل‌ها، API، قالب HEX و نام کلیدهای روی صفحه‌کلید ترجمه نمی‌شوند.
عددهای قابل خواندن برای کاربر در حالت فارسی با `nexDigits` نمایش داده می‌شوند؛
ورودی‌های فنی مانند نشانی، کد رنگ، کلید API و نام فایل قالب خود را حفظ می‌کنند.

نام کلیدها در `apps/desktop/lib/l10n/shortcut_labels.dart` متمرکز است.
راهنمای مستقل کلیدها چپ‌به‌راست نمایش داده می‌شود؛ برای اصلاح جهت متن هیچ
کاراکتر کنترلی نامرئی در ترجمه یا محتوای یادداشت ذخیره نمی‌شود.

منابع ترجمه: `app_en.arb` و `app_fa.arb`، همراه با دو نگاشت
`desktop_strings.dart` و `intelligence_strings.dart`.
`utility_strings.dart` نسخهٔ تولیدشدهٔ کلیدهای `utility*` است.
کنترل یکپارچگی با `python tools/check_l10n_parity.py` اجرا می‌شود.
